### 数据格式和含义

#### RDAP

RDAP（Registration Data Access Protocol，注册数据访问协议）文件是一种用于访问域名和 IP 地址注册数据的协议文档。

RDAP 文件通常包含有关域名、IP 地址块、自治系统编号（ASN）等注册信息，包括注册者的联系信息、注册日期、到期日期等。

### spider

#### 函数解释

1. **`__init__`**
    
    - **作用**：初始化 `AS_Spider` 类的实例。
    - **详细说明**：
        - 调用父类的初始化方法。
        - 根据 `enable_DB` 标志，从数据库或 CSV 文件中加载 ASN 数据。
        - 如果启用了增量下载，则对数据进行过滤和处理。
2. **`run`**
    
    - **作用**：主运行方法，负责分组并发处理数据。
    - **详细说明**：
        - 如果启用了增量下载，则直接返回。
        - 根据 `source` 字段对数据进行分组。
        - 使用 `gevent` 协程并发处理每个分组的数据，调用 `__download_for_as` 方法。
3. **`run_for_append`**
    
    - **作用**：增量更新方法，处理增量数据。
    - **详细说明**：
        - 使用 `gevent` 协程处理增量更新的数据，调用 `__download_for_as` 方法。
4. **`__rdap_as_query`**
    
    - **作用**：RDAP 和 WHOIS 查询方法。
    - **详细说明**：
        - 查询 RDAP 数据，如果失败则转用 WHOIS 查询。
        - 返回查询结果和相关实体列表。
5. **`__download_for_as`**
    
    - **作用**：下载和处理 AS 信息。
    - **详细说明**：
        - 下载和处理 AS 信息，使用缓存机制批量存储数据。
        - 根据 `enable_DB` 标志，将数据存储到数据库或 CSV 文件中。
        - 支持批量存储和去重。
6. **`query_as_info`**
    
    - **作用**：查询单个 AS 信息，用于测试。
    - **详细说明**：
        - 调用 `__rdap_as_query` 方法查询单个 AS 信息。

#### 调用顺序

1. **初始化**：
    
    - 创建 `AS_Spider` 实例时，调用 `__init__` 方法进行初始化。
2. **运行主流程**：
    
    - 调用 `run` 方法，根据 `source` 字段对数据进行分组。
    - 使用 `gevent` 协程并发处理每个分组的数据，调用 `__download_for_as` 方法。
3. **增量更新**：
    
    - 调用 `run_for_append` 方法，处理增量数据，调用 `__download_for_as` 方法。
4. **查询单个 AS 信息**：
    
    - 调用 `query_as_info` 方法，用于测试，调用 `__rdap_as_query` 方法。

#### 整体梳理

1. **初始化**：
    
    - 创建 `AS_Spider` 实例，加载和处理数据。
2. **主运行流程**：
    
    - 调用 `run` 方法，分组并发处理数据。
    - 在 `run` 方法中，调用 `__download_for_as` 方法处理每个分组的数据。
3. **增量更新**：
    
    - 调用 `run_for_append` 方法，处理增量数据。
    - 在 `run_for_append` 方法中，调用 `__download_for_as` 方法处理增量数据。
4. **查询单个 AS 信息**：
    
    - 调用 `query_as_info` 方法，用于测试，调用 `__rdap_as_query` 方法查询单个 AS 信息。

通过上述调用顺序，整个代码实现了从数据加载、处理、并发查询到存储的全流程。

## dnsdata - DNS 数据的下载和预处理

### Server 端

- `server_run.py`：可以为前端提供接口的后端。有任务列表展示、发布任务、任务进度检测以及任务结果导出四部分。任务发布可以用多个 client, 但需要用英文逗号“,”分割。
- `distributed.py`：负责把任务 (待爬取域名列表) 切分并分发给指定服务器，它会调用远程 client 的 `start_spider.sh`。程序通过 `server_run.py` 执行任务发布时，会调用该脚本。它有两个输入参数 (文件), server_file 指定要分发的服务器配置文件, task_file 指定任务文件。
- `collect.py`：负责从各个 client 端收集某个任务的执行结果并进行计数。程序通过 `server_run.py` 执行任务进度检测时，会调用该脚本。它有一个输入参数 (文件), server_file 指定任务分发的 client 文件。
- `task/, result/, count/`：这三个文件夹分别负责存储任务文件、结果文件和任务进度。
- `server_list.json`： `server_run.py` 需要的服务器连接信息。

### Client 端

- `spider.py`：爬虫，负责 DNS 解析和网站关键信息爬取。同时保存了两份结果，一份为本地存档，一份为负责远程传输。
- `start_spider.sh`：Server 端远程调用时会执行此脚本以启动爬虫。
- `stop_spider.sh`：停止所有相关任务。
