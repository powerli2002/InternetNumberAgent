## DNSdata
定时读取 DNS 解析日志，提取日志中 A 记录和 AAAA 记录，获取域名列表和对应的解析 IP 地址。
**提取子域名信息：**
访问每个网址，解析 html 页面，找页面中出现的子域名 (href 链接)
**解析 DNS 与网站基础信息:**
将域名，html 主要部分，子域名输出到文件。（附带 domain_cn 的原本的列）
[DNS云学堂 | 权威DNS那些事儿（上） - 域名国家工程研究中心 - 博客园](https://www.cnblogs.com/zdns/p/12858010.html)

| 记录类型   | 作用                 |
| ------ | ------------------ |
| A 记录    | 将主机名映射到 IPv4 地址      |
| NS 记录   | 指定哪些 DNS 服务器负责某个域或子域 |
| AAAA 记录 | 将主机名映射到 IPv6 地址      |

### get_bgp_data
转成 rib 格式文件，通过 `rib_parser.py` 解析器提取信息，
最终输出为：`rib_data_{date}.csv `

| 列                 | 描述                          |
| ----------------- | --------------------------- |
| **v4Upstream**    | IPv4 地址空间中指向该自治系统的上游路由器。    |
| **v4Peer**        | IPv4 地址空间中与该自治系统直接连接的对等路由器。 |
| **v4Downstream**  | IPv4 地址空间中从该自治系统出发的下游路由器。   |
| **v4Propagation** | IPv4 地址前缀在该自治系统内部传播的路由器。    |
| **v4Prefixes**    | 该自治系统广告的 IPv4 前缀。           |
| **asn**           | 自治系统号码，用于唯一标识互联网上的一个或一组网络。  |

## RIRdata
1.获取五大洲分配机构数据，获取 IP 地址权威分配信息、AS 号分配信息、RIR 地址、AS 对象注册信息，产生 inet6num/route/aut-num、organization/person/role 对象信息。

下属会员单位维护后，

| 文件名                                 | 描述                                   |
| :---------------------------------- | ------------------------------------ |
| afrinic_as-block_whois_info.csv     | AS 块信息。                               |
| afrinic_aut-num_whois_info.csv      | 自治系统号**注册**详细信息。（下属单位注册）             |
| afrinic_inet6num_whois_info.csv     | IPv6 网络**注册**的详细信息                    |
| afrinic_inetnum_whois_info.csv      | IPv4 网络**注册**的详细信息                    |
| afrinic_irt_whois_info.csv          | 事件反应小组 (IRT) 的详细信息                    |
| afrinic_organisation_whois_info.csv | 组织（organisation）的详细信息                |
| afrinic_person_whois_info.csv       | 个人信息                                 |
| afrinic_route_whois_info.csv        | 路由信息，包括路由前缀、描述和相关组织信息。（会员单位路由宣告）     |
| afrinic_route-set_whois_info.csv    | 路由集合（route-set）的详细信息，包括描述、组织信息和管理联系人 |
| afrinic_mntner_whois_info.csv       | 维护者（mntner）的详细信息                     |

inetnum 主要用于描述 IP 地址块的所有权、分配状态以及相关的管理信息。
route 主要是互联网注册机构记录的路由相关信息。描述路由注册信息，表明某个 IP 前缀是由哪个 AS 宣告的。表示此 IP 前缀被合法分配给某 AS
路由宣告信息：就是各种路由快照，指通过 BGP 在互联网上实际传播的路由信息

2.获取 delegate 分配数据信息，处理后：转化为 asn 和 ipv4，ipv6 信息。

读取 asn.csv 分配文件，然后使用 rdap 进行补充，如果失败则使用 whois 信息补充。

`{rir}_ip_rdap_info.csv`

## Fusionprocessing
auto 中运行的功能：

| 功能描述          | 类名                        | 主要功能                             |
| ------------- | ------------------------- | -------------------------------- |
| AS 邮件地址生成     | `ASWithMailKey`           | 补充信息，添加 email_key                 |
| AS 组织分组       | `OrgAS`                   | 通过 AS 的 Whois 与 RDAP 数据生成组织机构映射  |
| AS 实体格式化器     | `ASEntityFormatter`       | 创建 AS 实体                         |
| 国家实体格式化器      | `CountryEntityFormatter`  | 创建国家实体                           |
| 组织实体格式化器      | `OrgEntityFormatter`      | 创建组织实体                           |
| IP BGP 格式化器   | `IPBGPFormatter`          | 创建 IPv4/v6 BGP 实体                |
| IP 注册格式化器     | `IPRegFormatter`          | 创建 IPv4/v6 inetnum, RDAP 和路由注册实体 |
| IP 权威分配数据格式化器 | `IPDelegateFormatter`     | 创建 IPv4/v6 分配实体                  |
| 行业实体格式化器      | `IndustryEntityFormatter` | 创建行业实体                           |
| 实体持久化         | `EntityPersistence`       | 将不同类型的实体数据写入数据库                  |
