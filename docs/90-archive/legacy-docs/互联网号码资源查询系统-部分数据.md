关于 delegated-apnic-extended-latest 等分配数据：
[RIR 统计数据交换格式 – APNIC --- RIR statistics exchange format – APNIC](https://www.apnic.net/about-apnic/corporate-documents/documents/resource-guidelines/rir-statistics-exchange-format/#Format)

```
#### The version line 版本线
version|registry注册机构|serial序列号|records记录数|startdate|enddate|UTCoffset日期偏移量
2.3|apnic|20240812|171362||20240809|+1000

#### The summary line 概要线
registry|*|type|*|count|summary
apnic|*|asn|*|13319|summary
apnic|*|ipv4|*|55122|summary
apnic|*|ipv6|*|102921|summary

#### 记录格式
registry|cc组织|type|start|value|date|status[|extensions...]
apnic|AU|ipv4|1.0.0.0|256|20110811|assigned|A91872ED
apnic|CN|ipv4|1.0.1.0|256|20110414|allocated|A92E1062
```

记录格式：
start：“第一个地址”。
value：如果是 IPv4 地址，则为该范围内的主机计数，对于 IPv6 地址，该值将是来自 `<start>` 的“第一个地址”值的 CIDR 前缀长度。对于“asn”类型的记录，该数字是从该起始值开始的 AS 计数。
**allocated**: 意味着 IP 块被分配给中介（例如 ISP 或本地注册机构）。
**assigned**: IP 块直接分配给最终用户或组织。
extensions: 行上的任何额外数据都是未定义的，但应符合上面使用的字段分隔符的使用。(A91872ED 唯一参考 ID。)

### format 数据
