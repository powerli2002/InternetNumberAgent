## Docker Compose 导入（推荐）

默认只写入 16 张实体表（不生成 `csv__*` 原始表），并清理非核心表，适合面试演示与快速落地。Docker Compose 默认不加载 `audit_trigger.sql`，避免生成 `_audit` 表。

```bash
# 1) 启动 PostgreSQL（数据持久化到项目目录 mount/pgdata）
docker compose -f docker/docker-compose.yml up -d postgres

# 2) 构建 CSV 导入镜像
docker compose -f docker/docker-compose.yml build loader

# 3) 执行导入（仅 16 表，如已有数据则跳过）
docker compose -f docker/docker-compose.yml run --rm loader

# 仅清理非核心表（不导入）
# docker compose -f docker/docker-compose.yml run --rm loader python scripts/load_all_csv.py --config conf/config.docker.yaml --root /work --cleanup-only

# 强制清理并确保 16 表存在（缺失或无数据时导入）
# docker compose -f docker/docker-compose.yml run --rm loader python scripts/load_all_csv.py --config conf/config.docker.yaml --root /work --ensure-core
```

导入日期默认读取 `conf/config.docker.yaml` 的 `current_date`；如需指定日期，可在 `docker compose run` 后追加 `--date YYYY-MM-DD`。

2. **查看所有数据库** ：使用 `\l` 查看所有数据库。
3. **连接到特定数据库** ：使用 `\c database_name` 连接到目标数据库。
4. **查看表** ：使用 `\dt` 查看数据库中的所有表。
5. **查看表结构** ：使用 `\d table_name` 查看表的详细结构。
6. **查询表数据** ：使用 `SELECT * FROM table_name;` 查看表中的数据。
7. **退出** ：使用 `\q` 退出 PostgreSQL 命令行。
