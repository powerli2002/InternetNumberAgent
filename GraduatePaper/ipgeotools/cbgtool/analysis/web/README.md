# 地理位置预测可视化工具

基于Leaflet.js实现的交互式地理位置预测可视化工具，用于分析预测位置和真实位置之间的关系，以及计算预测位置的交圆。

## 功能特点

- 显示预测位置（蓝色标记）、真实位置（红色标记）和探针（绿色标记）
- 鼠标悬停时高亮预测位置与真实位置之间的连线
- 计算并显示预测位置之间的交圆（基于最近的3个预测点）
- 显示统计信息（预测位置、真实位置和探针的数量）
- 支持显示/隐藏不同类型的数据点和图形元素

## 使用方法

1. 确保数据文件路径正确：
   - 预测和真实位置数据：`../../data/output/user_result_loc_ori.json`
   - 探针数据：`../../data/format/user_probes.json`
   - 交圆数据：   `../../data/output/user_circle_map.json`

2. 在项目可视化目录启动服务器：
   ```
   cd analysis/web
   npm start
   ```
   然后访问 `http://localhost:8080`
   注意映射的端口

3. 交互说明：
   - 鼠标悬停在任意标记上查看详细信息
   - 鼠标悬停在预测位置或真实位置上，会高亮显示它们之间的连线
   - 使用页面上的复选框控制不同元素的显示/隐藏

## 技术说明

- 地图使用 [Leaflet.js](https://leafletjs.com/) 库实现
- 交圆计算基于每个预测点与其最近的3个预测点之间的距离
- 地图默认居中显示美国地区

## 数据格式要求

1. 预测与真实位置数据格式：
   ```json
   [
     ["ID", 其他信息, [预测纬度, 预测经度], [真实纬度, 真实经度], ...]
   ]
   ```

2. 探针数据格式：
   ```json
   [
     {
       "id": "探针ID",
       "geometry": {
         "coordinates": [纬度, 经度]
       },
       ...
     }
   ]
   ```
