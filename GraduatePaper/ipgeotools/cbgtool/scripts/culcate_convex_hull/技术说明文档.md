### 3. 离群点检测

#### 3.1 IQR方法
```python
def detect_outliers(self, df: pd.DataFrame, method='iqr', factor=2.5):
    # 使用IQR方法检测离群点
    Q1_lat = df['ms'].quantile(0.25)
    Q3_lat = df['ms'].quantile(0.75)
    IQR_lat = Q3_lat - Q1_lat
    
    # 定义离群点
    outlier_condition = (
        (df['ms'] < (Q1_lat - factor * IQR_lat)) |
        (df['ms'] > (Q3_lat + factor * IQR_lat)) |
        (df['distance_km'] < (Q1_dist - factor * IQR_dist)) |
        (df['distance_km'] > (Q3_dist + factor * IQR_dist))
    )
```

**技术实现**:
- 支持多种离群点检测方法：IQR、Z-score、比率方法
- 可调节的阈值因子（默认2.5）
- 同时考虑延迟和距离的异常值

#### 4.2 上下边界分离算法
```python
# 找到最左和最右的点
leftmost_idx = np.argmin(hull_points[:, 0])
rightmost_idx = np.argmax(hull_points[:, 0])

# 使用叉积判断点在直线的上方还是下方
v1 = rightmost_point - leftmost_point
v2 = point - leftmost_point
cross_product = v1[0] * v2[1] - v1[1] * v2[0]

if cross_product >= 0:  # 上方
    upper_hull.append(point)
else:  # 下方
    lower_hull.append(point)
```

**技术要点**:
- 基于最左-最右点连线分离上下边界
- 使用叉积计算判断点相对位置
- 确保边界点正确分类

#### 5.1 多项式拟合

#### 5.2 距离-延迟转换系数计算
```python
# 线性拟合: latency = slope * distance + intercept
linear_fit = np.polyfit(all_distances, all_latencies, 1)
slope = linear_fit[0]  # ms/km

# 转换为速度: speed = distance / time
speed_mps = 1000 / slope  # m/ms = 1000 * m/s

# 光速 c = 299,792,458 m/s
speed_of_light = 299792458  # m/s

# 计算是几分之一光速
delta = speed_mps / speed_of_light
```

**理论基础**:
- 延迟 = 距离 / 速度
- 斜率 = 延迟 / 距离 = 1 / 速度
- 速度 = 1 / 斜率
- δ = 计算速度 / 光速
