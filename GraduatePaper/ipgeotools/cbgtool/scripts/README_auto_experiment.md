# CBG自动实验脚本使用说明

## 概述

`auto_experiment.py` 是一个自动化实验脚本，用于系统地运行CBG和Octant地理定位方法的所有参数组合实验。

该脚本会自动：
- 生成所有可能的参数组合
- 检查并跳过已存在的实验结果
- 按顺序执行所有待完成的实验
- 提供详细的进度报告和统计信息

## 实验参数配置

### Delta值（距离延迟转换系数）
- `0.398` - 默认值
- `1/3` - 三分之一光速 (≈0.333)
- `1/6` - 六分之一光速 (≈0.167)
- `1/9` - 九分之一光速 (≈0.111)
- `2/9` - 九分之二光速 (≈0.222)

### 探针选择策略
- `all` - 使用所有可用探针
- `l3` - 使用延迟最短的3个探针
- `d3` - 使用地理距离最短的3个探针
- `t3` - 使用能形成包含目标三角形的最近3个探针

### 定位方法
- `cbg` - CBG约束边界地理定位方法
- `octant` - Octant环形区域定位方法

### 实验组合总数
5个Delta值 × 4个策略 × 2个方法 = **40个实验组合**

## 使用方法

### 1. 查看实验状态
```bash
# 列出所有实验组合和当前状态
python scripts/auto_experiment.py --list
```

### 2. 模拟运行（推荐测试）
```bash
# 干运行模式，不实际执行实验
python scripts/auto_experiment.py --dry-run

# 限制处理目标数量进行快速测试
python scripts/auto_experiment.py --dry-run --limit 10
```

### 3. 执行实际实验
```bash
# 运行所有待执行的实验，默认限制1000个目标
python scripts/auto_experiment.py

# 自定义目标数量限制
python scripts/auto_experiment.py --limit 500

# 运行更大规模的实验
python scripts/auto_experiment.py --limit 5000

# 使用离线模式（不获取地址信息）
python scripts/auto_experiment.py --offline
```

## 命令行参数

- `--limit N`: 设置每个实验处理的目标数量限制（默认：1000）
- `--dry-run`: 模拟运行模式，不实际执行实验，用于测试
- `--list`: 仅列出实验状态，不执行实验
- `--offline`: 离线模式，不获取地址信息（避免网络请求错误）

## 输出文件

实验结果文件保存在 `data/output/` 目录下，文件命名格式：
- 结果文件：`user_result_loc_{method}_{delta}_{strategy}.json`
- 圆形数据：`user_circle_map_{method}_{delta}_{strategy}.json`

例如：
- `user_result_loc_cbg_0.398_t3.json` - CBG方法，delta=0.398，t3策略的定位结果
- `user_result_loc_octant_1_3_all.json` - Octant方法，delta=1/3，all策略的定位结果

## 缓存和性能优化

脚本会自动：
1. 检查已存在的实验结果，避免重复执行
2. 为相同delta值的实验重用位置缓存数据
3. 提供详细的进度报告

## 错误处理和恢复机制

脚本包含多层错误处理机制：

1. **缓存文件错误处理**：
   - 健壮的JSON解析和数据验证
   - 跳过无效的缓存条目
   - 自动回退到其他可用缓存

2. **网络错误处理**：
   - 请求超时处理
   - 连接错误处理
   - 离线模式选项

3. **自动重试机制**：
   - 最多重试2次
   - 递增等待时间
   - 针对不同错误类型的特定处理

4. **中断恢复**：
   - 安全中断和恢复
   - 跳过已完成的实验

## 日志和监控

- 实验初始化信息

## 注意事项

1. **资源消耗**：每个实验可能需要几分钟到几十分钟，取决于 `--limit` 参数
2. **磁盘空间**：结果文件可能很大，特别是包含大量目标的实验
3. **中断恢复**：脚本可以安全中断，重新运行时会自动跳过已完成的实验
4. **错误处理**：如果某个实验失败，脚本会继续执行其他实验

## 性能建议

- 首次运行建议使用较小的 `--limit` 值（如100-500）进行测试
- 对于大规模实验，建议在后台运行或使用屏幕会话
- 监控磁盘空间，确保有足够空间存储结果文件
- 如果遇到网络问题，使用 `--offline` 模式

## 故障排除

如果实验失败：
1. 检查日志中的错误信息
2. 确保所有依赖数据文件存在
3. 验证 `data/output` 目录的写权限
4. 对于特定实验组合的问题，可以单独运行CBGTool进行调试
5. 如果遇到网络相关错误，尝试使用 `--offline` 模式

## 扩展和自定义

要添加新的实验参数：
1. 修改 `AutoExperiment` 类中的参数配置
2. 更新 `format_delta_for_filename` 方法处理新的delta格式
3. 确保文件命名格式兼容现有系统
