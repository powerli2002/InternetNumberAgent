# 研究空白与论文论点

## 核心论点（当前实验支持的）

1. **Agent 调度框架的价值**：在数据完整时，调度层可通过选择合适工具降低成本、保持精度。
2. **工具互补性**：rDNS 证据独立于 ModuGeo 的前缀先验，理论上可降低系统性误差。
3. **数据稀疏是主要瓶颈**：中国 IPv6 PTR 覆盖率极低（<1%），是 rDNS 工具无效的根因。

## 待补充论点

- [ ] CBG 约束数量与精度的定量关系（需要 E03）
- [ ] 调度器在工具有效时的收益（需要覆盖率提升后重新评测）
- [ ] 与纯 ModuGeo 相比，多工具融合在哪类目标上有优势（分省市分析）

## 已知负面结果（可写进论文）

- 中国 IPv6 PTR 部署稀疏：21088 个 IP 仅 212 个有 PTR（1%）
- 被动 IPDB 本地无可用数据库，商业方案受限
- RIPE Atlas API 401，外部主动探测受限
