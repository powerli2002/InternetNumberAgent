**专利名称**：一种多轮工具调度 IPv6 地理位置推断方法及系统  
**专利类型**：发明专利  
**撰写日期**：2026-06-12

---

## 一、技术领域

本发明涉及网络测量与地理位置推断领域，具体涉及一种将大语言模型 Agent 与可验证强化学习相结合，通过多轮动态工具调度对 IPv6 地址进行地理位置推断的方法及系统。

---

## 二、背景技术

现有 IPv6 地理位置推断方法存在以下缺陷：

**缺陷一：静态融合无法感知工具质量。** 现有方法对多源定位工具（主动测量、反向 DNS、IP 数据库）的结果进行固定权重加权，无法根据单次调用的覆盖状态、约束充分性和结果可信度动态调整决策。

**缺陷二：单步决策缺乏证据积累能力。** 现有调度器对每个目标仅执行一次工具选择动作，不能根据已获取证据的质量决定是否继续取证、切换工具或放弃输出。

**缺陷三：IPv6 工具覆盖率不均衡。** rDNS PTR 记录稀疏、主动测量依赖高质量探针、被动 IP 数据库 IPv6 覆盖有限，导致工具在不同目标上的实际有效性差异极大，静态策略无法处理此类不确定性。

**缺陷四：缺乏可信停止与拒答机制。** 现有方法强制输出城市级坐标，当证据不足或工具结果互相冲突时，无法选择降低输出粒度或拒绝回答，导致高置信度错误输出。

## 三、独立权利要求对应的技术方案

### 3.1 权利要求一：Agent 训练方法

**方案概述**：一种基于监督微调与可验证强化学习的 IPv6 地理位置推断 Agent 训练方法。

#### 3.1.1 数据划分

给定目标 IPv6 地址集合 $\mathcal{I} = \{ip_1, ip_2, \ldots, ip_N\}$，对每个地址提取 /48 前缀：

$$p(ip) = ip \gg (128 - 48)$$

按前缀对地址集合进行隔离划分，得到不相交的前缀子集 $\mathcal{P}_{train}$、$\mathcal{P}_{val}$、$\mathcal{P}_{test}$，满足：

$$\mathcal{P}_{train} \cup \mathcal{P}_{val} \cup \mathcal{P}_{test} = \mathcal{P}, \quad \mathcal{P}_{train} \cap \mathcal{P}_{val} = \mathcal{P}_{val} \cap \mathcal{P}_{test} = \mathcal{P}_{train} \cap \mathcal{P}_{test} = \emptyset$$

对应地址划分为：

$$\mathcal{I}_{split} = \{ ip \in \mathcal{I} \mid p(ip) \in \mathcal{P}_{split} \}, \quad split \in \{train, val, test\}$$

私有真值 $\mathcal{Y}^* = \{(lat_i^*, lon_i^*)\}_{i=1}^N$ 不写入任何模型可见字段。

#### 3.1.2 监督微调冷启动

构造教师轨迹集合 $\mathcal{D}_{SFT}$，每条轨迹为：

$$\tau = (o_0, a_0, o_1, a_1, \ldots, o_T, a_T)$$

其中 $o_t$ 为第 $t$ 步的工具观察，$a_t$ 为 Agent 动作。轨迹覆盖四类场景：工具可用且有效、工具不可用（返回 `unavailable`）、结果冲突、拒答或降粒度输出。

对语言模型参数 $\theta$ 进行最大似然微调：

$$\mathcal{L}_{SFT}(\theta) = -\sum_{\tau \in \mathcal{D}_{SFT}} \sum_{t=0}^{T} \log \pi_\theta(a_t \mid o_0, a_0, \ldots, o_t)$$

#### 3.1.3 可验证强化学习优化（GRPO）

对同一目标 $ip_i$ 采样 $G$ 条多轮轨迹 $\{\tau_i^{(g)}\}_{g=1}^G$，在隔离环境中执行工具调用，以隐藏真值计算各轨迹奖励 $r_i^{(g)}$。

组内归一化相对优势：

$$\hat{A}_i^{(g)} = \frac{r_i^{(g)} - \mu_i}{\sigma_i + \epsilon}, \quad \mu_i = \frac{1}{G}\sum_{g=1}^G r_i^{(g)}, \quad \sigma_i = \sqrt{\frac{1}{G}\sum_{g=1}^G (r_i^{(g)} - \mu_i)^2}$$

策略优化目标：

$$\mathcal{L}_{GRPO}(\theta) = -\mathbb{E}\left[\hat{A}_i^{(g)} \cdot \log \pi_\theta(\tau_i^{(g)})\right] + \beta \cdot D_{KL}(\pi_\theta \| \pi_{ref})$$

其中 $\pi_{ref}$ 为 SFT 后的参考策略，$\beta$ 为 KL 惩罚系数，防止策略偏离过远。

#### 3.1.4 奖励函数设计

总奖励由以下各项组成：

$$R = R_{geo} + \lambda_1 R_{improve} + \lambda_2 R_{appl} + \lambda_3 R_{tail} + \lambda_4 R_{gran} - \lambda_5 C_{cost} - \lambda_6 C_{invalid} - \lambda_7 C_{fusion}$$

各项定义如下：

**地理误差奖励**，以球面距离衡量，$d_0$ 为归一化基准距离（如 100 km）：

$$R_{geo} = \max\left(0,\ 1 - \frac{d(\hat{y},\ y^*)}{d_0}\right)$$

其中 $d(\hat{y}, y^*)$ 为 Haversine 距离：

$$d(\hat{y}, y^*) = 2R_E \arcsin\sqrt{\sin^2\!\frac{\Delta\phi}{2} + \cos\phi_1\cos\phi_2\sin^2\!\frac{\Delta\lambda}{2}}$$

**相对改善奖励**，相对基础定位器输出 $\hat{y}_{base}$ 的误差改善比例：

$$R_{improve} = \frac{\max\left(0,\ d(\hat{y}_{base}, y^*) - d(\hat{y}, y^*)\right)}{d(\hat{y}_{base}, y^*) + \epsilon}$$

**工具适用性判断奖励**，$K$ 为本次轨迹中工具调用总次数，$\mathbb{1}[\cdot]$ 为正确判断指示函数：

$$R_{appl} = \frac{1}{K}\sum_{k=1}^{K} \mathbb{1}\left[\text{appl\_judgment}_k = \text{correct}\right]$$

**尾部纠错奖励**，仅对基础定位器误差超过阈值 $d_{tail}$ 的样本生效：

$$R_{tail} = \mathbb{1}\left[d(\hat{y}_{base}, y^*) > d_{tail}\right] \cdot R_{improve}$$

**输出粒度奖励**，Agent 选择城市级、省级或拒答时，依据与真实所需粒度的匹配程度给分：

$$R_{gran} \in \{1.0,\ 0.5,\ 0.0,\ -0.5\}$$

**调用成本惩罚**，$c_k$ 为第 $k$ 次调用的归一化成本：

$$C_{cost} = \sum_{k=1}^{K} c_k \cdot \mathbb{1}\left[\text{call}_k\ \text{is redundant or invalid}\right]$$

**非法动作与错误融合惩罚** $C_{invalid}$、$C_{fusion}$ 为计数型惩罚项，各自独立计算。

### 3.2 权利要求二：多轮推断方法

**方案概述**：使用权利要求一训练的 Agent 对目标 IPv6 地址进行多轮推断的方法。

#### 3.2.1 状态空间

Agent 在第 $t$ 步的可观察状态为：

$$s_t = (x_{ip},\ x_{net},\ \hat{y}_{base},\ conf_{base},\ \{(tool_k, obs_k, status_k)\}_{k < t},\ budget_t)$$

- $x_{ip}$：目标 IPv6 的前缀特征（匿名化，不含真实坐标）
- $x_{net}$：ASN、运营商、BGP 前缀归属等网络属性
- $\hat{y}_{base}, conf_{base}$：基础定位器输出坐标与置信度
- $(tool_k, obs_k, status_k)$：已执行工具的结构化观察与状态
- $budget_t$：剩余步骤与调用预算

Agent **不可观察**真实坐标 $(lat^*, lon^*)$、行政区划真值及测试集近邻真值。

#### 3.2.2 动作空间

$$\mathcal{A} = \mathcal{A}_{inspect} \cup \mathcal{A}_{query} \cup \mathcal{A}_{compare} \cup \mathcal{A}_{output}$$

| 动作组 | 动作示例 |
|--------|----------|
| $\mathcal{A}_{inspect}$：适用性检查 | `inspect_tool_applicability(tool_id)` |
| $\mathcal{A}_{query}$：工具调用 | `query_rdns`, `run_active_solver`, `query_passive_db`, `query_whois_bgp` |
| $\mathcal{A}_{compare}$：结果比较 | `compare_candidates(cand_list)` |
| $\mathcal{A}_{output}$：终止输出 | `finalize(ŷ, conf)`, `abstain(granularity)` |

#### 3.2.3 工具观察结构

每次工具调用返回结构化状态，包含六类失败原因：

$$status \in \{ok,\ input\_missing,\ coverage\_miss,\ assumption\_violation,\ low\_quality,\ conflict,\ unavailable\}$$

#### 3.2.4 停止条件

Agent 在满足以下任一条件时终止：

$$\text{stop} \iff \left(a_t \in \mathcal{A}_{output}\right) \lor \left(budget_t \leq 0\right) \lor \left(t \geq T_{max}\right)$$

最终输出为位置估计 $\hat{y}$、置信度 $conf \in [0,1]$、证据链 $E = \{(tool_k, obs_k)\}$，或在证据不足时输出降粒度结论（省级）或拒答 $\perp$。

### 3.3 权利要求三：无泄漏训练数据构建方法

**方案概述**：一种用于 Agent 训练的前缀隔离、真值分离、确定性回放的数据构建方法。

#### 3.3.1 真值分离

定义私有真值集合：

$$\mathcal{Y}^* = \{(lat_i^*, lon_i^*, region_i^*, city_i^*)\}_{i=1}^N$$

构造模型可见任务时，对每条样本 $x_i$ 执行字段过滤，确保：

$$x_i \cap \mathcal{Y}^* = \emptyset$$

即真实坐标、行政区划名称（含中英文）均不出现在模型可见字段中。

#### 3.3.2 自动泄漏扫描

对所有模型可见文本字段进行扫描，泄漏检测函数为：

$$\text{leak}(x_i) = \mathbb{1}\left[\exists\ v \in \mathcal{Y}_i^* \text{ s.t. } v \in \text{str}(x_i)\right]$$

要求对全量数据满足：

$$\sum_{i=1}^N \text{leak}(x_i) = 0$$

#### 3.3.3 确定性离线回放

对每个目标 $ip_i$ 和每个工具 $tool_j$，预先离线执行并记录：

$$replay_{i,j} = (input_{i,j},\ output_{i,j},\ status_{i,j},\ cost_{i,j})$$

确定性验证：对同一输入两次执行结果完全一致：

$$\forall\ i, j:\ replay_{i,j}^{(1)} = replay_{i,j}^{(2)}$$

训练时 Agent 从回放记录中加载工具结果，保证实验可复现性与训练过程与真值的物理隔离。

| 注意点 | 说明 |
|--------|------|
| 权利要求不写性能数字 | "改善率 5.17%"等实验结果不写入权利要求，仅可出现在说明书实施方式中 |
